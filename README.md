# 超级像素冒险 (mario-game)

一个用 **纯 JDK 标准库** 托管的《超级马里奥》风格横版卷轴过关游戏。游戏本体是一个自包含的 `index.html`（Canvas + 原生 JS，内联 CSS），由 Java 入口类用 `com.sun.net.httpserver.HttpServer` 在本地起静态服务并自动打开浏览器。

> 无任何第三方依赖，IDEA 导入 Maven 后 **离线** 即可编译运行。

---

## 在 IDEA 里怎么跑起来

1. **打开项目**：IntelliJ IDEA → `File` → `Open` → 选择本项目根目录（含 `pom.xml` 的文件夹）→ 等待右下角 Maven 导入完成（无需联网下载依赖）。
2. **运行入口**：在项目视图中打开 `src/main/java/com/example/mariogame/MarioGameServer.java`，点击类声明左侧的绿色 ▶ 运行 `main` 方法（或右键 → `Run 'MarioGameServer.main()'`）。
3. **自动开浏览器**：控制台会打印访问地址（默认 `http://127.0.0.1:8080/`），并自动调用系统默认浏览器打开游戏页面。
4. **停止**：在 IDEA 运行窗口点击红色 ■，或按 `Ctrl+C`。

> 也可用命令行：`mvn -q -DskipTests package` 后执行 `java -jar target/mario-game.jar`。

## 已实现的需求点

**核心玩法**
- 横版卷轴 + 镜头跟随，左右移动、跳跃、踩踏敌人、顶砖块，到达旗杆通关。

**核心规则**
- 可变跳跃高度（按住更高、松开截断）、土狼时间（coyote time）、跳跃缓冲；地面摩擦 + 空中控制系数，重力明确。
- 踩踏敌人消灭并弹起；侧向/底部触碰受伤：小马里奥死亡扣命，大马里奥变小并进入无敌闪烁帧。
- 顶问号砖块随机产出 金币 / 红蘑菇 / 花朵 / 星星，含砖块顶起动画与道具冒出动画。
- 红蘑菇：体型变大并抗一次伤害；花朵：获得火球（可发射击杀敌人）；星星：短暂无敌（彩虹闪烁、触碰即消灭敌人）。
- 初始 3 条生命，金币满 100 换 1 条命；HUD 显示金币、生命、分数、时间、关卡。
- 单次触碰只触发一次受伤逻辑，含无敌帧冷却。

**关卡内容**
- 地面砖、管道（实体障碍）、高台、坑（掉落即死）、水平往复移动平台（角色站上后跟随移动）。
- 终点旗杆触碰即通关，通关界面显示得分 / 剩余时间 / 用时 / 金币 / 生命。

**体验**
- 跳跃手感柔和，反馈及时。
- 吃道具、踩敌人、顶砖块、受伤、死亡、通关均有 Web Audio API 合成音效 + 粒子/动画反馈。
- Canvas 程序化绘制像素风：天空、视差远山、云、灌木、砖块纹理、角色、敌人、道具动画。

**其他**
- 完整游戏循环：`requestAnimationFrame` + 固定时间步（1000/60ms 累加，最多补偿 5 步，防止低帧下穿模）。
- 代码分模块：游戏循环 / 实体 / 输入 / 碰撞 / 物理 / 渲染 / 音频。
- 敌人含板栗仔（Goomba）与乌龟（Koopa，可踩成龟壳并踢动）。
- 火球、粒子、砖块破碎动画、金币弹出动画。

## 项目结构

```
mario-game/
├── pom.xml                          # Maven 配置（JDK 1.8，无第三方依赖）
├── .gitignore
├── README.md
└── src/
    └── main/
        ├── java/com/example/mariogame/
        │   └── MarioGameServer.java # 入口：HttpServer 托管静态资源 + 自动开浏览器
        └── resources/
            └── static/
                └── index.html       # 游戏本体（自包含，CSS/JS 内联）
```

`index.html` 是自包含的（CSS/JS 全部内联），因此 **双击直接打开也能玩**（无需服务器），同时也能被 Java 服务器正确托管。

## 端口修改方式

默认从 `8080` 开始，被占用时自动顺延（最多尝试 50 个端口）。控制台会打印实际使用的地址。

如需固定端口，修改 `MarioGameServer.java` 中的常量：

```java
private static final int START_PORT = 8080;
```

## 常见问题

- **端口占用**：程序会自动顺延到下一个可用端口，无需手动处理；控制台打印的地址即为实际可访问地址。
- **JDK 版本**：`pom.xml` 的 `source/target` 设为 `1.8`，当前环境为 JDK 8。代码未使用 8 以上 API，因此在 JDK 11 / 17 上也可直接编译运行。若使用更高版本 JDK，可把 `<maven.compiler.source>` / `<target>` 改为对应版本。
- **浏览器未自动打开**：手动复制控制台打印的 `http://127.0.0.1:端口/` 到浏览器即可。
- **Maven 离线编译报错**：确认本地 Maven 仓库已有 `maven-compiler-plugin` / `maven-jar-plugin` / `maven-resources-plugin`（这些是 Maven 默认生命周期插件，通常随 Maven 安装已存在）。本项目不依赖任何第三方库。
- **音效无声**：浏览器策略要求用户先与页面交互，首次按键后会激活 AudioContext。

## 验证方式

- 编译：`mvn -q -DskipTests package`（或 `javac`）
- HTTP 检查：`Invoke-WebRequest http://127.0.0.1:8080/` 确认 `index.html` 返回 200。
- 页面加载：用浏览器打开后，在开发者工具 Console 确认无报错；开始界面显示「超级像素冒险」，按空格进入游戏后可移动跳跃。
